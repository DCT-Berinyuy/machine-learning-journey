# 🌱 Machine Learning Journey

From AI beginner to building an offline crop-disease diagnosis app.

I'm learning machine learning from scratch in the **Reliable & Efficient AI** research group at ICT University, Yaoundé, led by Dr. Fotsing Kuetche. My team works on **Project 2: an AI assistant that recognises tomato, tea, coffee and cocoa diseases from a phone photo, even without internet.**

This repo is my public learning log: what I learn each day, my experiments, my answers, and how each idea feeds into the project.

## 🎯 Objective
- Build solid ML foundations: models, loss, evaluation, overfitting
- Understand computer vision: pixels, convolutions, CNNs, transfer learning
- Make models small and fast enough to run offline on a cheap phone (TensorFlow Lite)
- Apply it all to Project 2, and test on real field photos, not only lab photos

## 📅 Daily Routine
**Read → Run → Check → Ask → Commit**
1. **Read** the day's lesson
2. **Run** the notebook in Zed, and break things on purpose
3. **Check** myself with the self-test before looking at any answers
4. **Ask** one good question at the check-in
5. **Commit** my notes, experiments and answers here
